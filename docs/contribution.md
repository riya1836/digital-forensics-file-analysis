# Team Contributions

## 1. Project Overview

The project was developed collaboratively by dividing the implementation into four major milestones. Each team member was primarily responsible for one milestone while also contributing to testing, debugging, integration, and documentation.

| Team Member | Primary Responsibility |
|---|---|
| Neha Dhope | M1 – File Scanning and Metadata Extraction |
| Mrunmayee Galande | M2 – Sequential Analysis |
| Nishita Borse | M3 – Parallel Analysis using OpenMP |
| Riya Dhande | M4 – Benchmarking and Performance Analysis |

---

## 2. Neha Dhope – M1: File Scanning and Metadata Extraction

### Primary Responsibilities

- Implemented the M1 file scanning module.
- Developed recursive directory traversal.
- Extracted required file metadata.
- Generated the intermediate metadata CSV used by later modules.
- Handled file paths, filenames, extensions, sizes, modification times, permissions, and hidden-file status.
- Implemented appropriate CSV formatting and escaping.
- Ensured compatibility with the Linux/Ubuntu execution environment.

### Testing and Validation

- Compiled and executed the M1 implementation.
- Tested recursive scanning on the project datasets.
- Verified metadata fields and generated CSV output.
- Checked handling of hidden files and files without extensions.
- Verified that the generated metadata could be consumed by M2 and M3.

### Documentation/Integration

- Documented the M1 module and its workflow.
- Assisted with integration of the M1 output with subsequent analysis modules.

### Primary Responsibilities

- Added support for configurable thread counts.
- Generated the parallel analysis output.
- Added parallel execution-time measurement.

### Testing and Validation

- Tested the implementation using multiple thread counts.
- Compared parallel results with sequential results.
- Verified record counts and logical consistency.
- Tested OpenMP compilation and execution on Linux/Ubuntu.
- Evaluated the effect of different thread counts on execution time.

### Documentation/Integration

- Documented the parallelization approach.
- Assisted with correctness comparison between M2 and M3.
- Assisted with integration of the parallel module into the overall workflow.

## 7. Integration Workflow

The contributions of the four members form a single processing pipeline:

```text
Input Dataset
     |
     v
M1 - File Scanning
     |
     v
intermediate/metadata.csv
     |
     +----------------------+
     |                      |
     v                      v
M2 - Sequential        M3 - Parallel
     |                      |
     v                      v
outputs/sequential.csv  outputs/parallel.csv
     |                      |
     +----------+-----------+
                |
                v
       M4 - Benchmarking
                |
                v
       Performance Results
       Speedup / Efficiency
                |
                v
          Graphs & Analysis
```

Each milestone therefore contributes a distinct stage while depending on the outputs and correctness of the preceding stages.

## 8. Contribution and Responsibility Statement

Each team member was primarily responsible for the implementation and validation of their assigned milestone. Team members reviewed their own work, tested their implementations, and collaborated during integration and debugging.

The final project represents the combined work of all team members across implementation, testing, performance evaluation, integration, and documentation.
